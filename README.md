# industrio

GTA industrial real-estate intelligence — maps, comps, and market dashboards
over leased / for-lease / sold TRREB data from Peel, Toronto, York, Halton,
and Durham.

**Live site:** https://charlesjoyce88.github.io/industrio
*(served from GitHub Pages — see `PUBLISH.md` for how it's deployed)*

---

## What's in here

| Path | What it is |
|------|------------|
| `/docs/` | What GitHub Pages actually serves. Regenerated by `scripts/build-public.py`; never edit by hand. |
| `/scripts/` | Build + ingest scripts. `build-public.py` scrubs PII and copies site assets to `/docs/`. |
| `*.html`, `*.js`, `*.css` at root | The site source. Edit here; the build step mirrors to `/docs/`. |
| `listings.json` | Local-only, full-PII data store written by the parsers. **Gitignored** — never committed. |
| `docs/listings.json` | Scrubbed public copy (broker name/phone/email removed). Committed. |
| `buildings.json` | 5,595 GTA buildings with lat/lng (FSA-centroid geocoded). |
| `parse-emails.py` | Broker email parser (CBRE, Colliers, Vanguard). Writes to `listings.json`. |
| `import-realm-pdfs.py` | Realm "Broker Full" PDF parser. Writes to `listings.json`. |
| `worker.js` | Cloudflare Worker for the `api.industrio.ai` backend (lease abstract, comps pool). Not served from Pages. |
| `realm-aggregate-2026.json` | GTA 2026 industrial-leased stats captured from Realm's dashboard. |
| `HANDOFF.md` | Session handoff notes for Claude. |
| `WORKER-DEPLOY.md` | Cloudflare Worker deployment runbook (for the API half). |
| `INGESTION.md` | TRREB / Realm email ingestion runbook. |

## Data flow

```
┌─────────────────┐    ┌─────────────────┐    ┌──────────────────┐
│  Email inbox    │    │  Realm PDFs     │    │  TRREB RESO API  │
│  (iCloud/Gmail) │    │  (realm-pdfs/)  │    │  (future)        │
└────────┬────────┘    └────────┬────────┘    └────────┬─────────┘
         │                      │                      │
         ▼                      ▼                      ▼
   parse-emails.py       import-realm-pdfs.py    fetch-trreb.py (TBD)
         │                      │                      │
         └──────────────────────┴──────────────────────┘
                                │
                                ▼
                        listings.json  (local, full PII)
                                │
                                ▼
                   scripts/build-public.py  (strips PII)
                                │
                                ▼
                        docs/listings.json  (committed)
                                │
                                ▼
                     GitHub Pages → public URL
```

Any new data source only has to end its pipeline at `listings.json`.
Everything downstream — the frontend, the dashboards, the publish step — is
source-agnostic.

## Publishing an update

```bash
# 1. Ingest whatever new data you have (any or all of these)
python parse-emails.py           # pulls from your email store
python import-realm-pdfs.py realm-pdfs/

# 2. Rebuild the public site
python scripts/build-public.py

# 3. Push
git add docs/ && git commit -m "publish: refresh site" && git push
```

GitHub Pages redeploys in about 30 seconds.

See `PUBLISH.md` for the full first-time setup.

## What's NOT on GitHub

- The raw `listings.json` with broker contact details (gitignored).
