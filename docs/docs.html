The AI prompts that power industrio

These are the live system prompts our extraction, analysis, and agent models run on. We publish them because transparent analytics require transparent models.

Data extraction & analysis

extractionMLS

1 · MLS Data Extraction

Extract all relevant industrial property attributes from this MLS listing. Return structured JSON with:

• Address
• Asking rent
• Additional rent / TMI
• Size (total, industrial %, office %)
• Clear height
• Shipping (number + type of doors)
• Power (amps, volts, phase)
• Parking count + ratio
• Zoning
• Availability date
• Whitebox status
• Photos (URLs)
• Listing agent contact
• Notes on condition
• Any red flags

Be concise and accurate.
analysiscomps

2 · Leased Comps Analysis

Analyze these leased comps and return:

• Achieved rent
• Free rent
• Tenant improvement allowances
• Lease term
• Effective rent
• Submarket comparison
• Trend direction
• Renewal vs new lease differences

Provide a summary for a tenant negotiating a renewal.
summarytenant-facing

3 · Space Summary

Create a concise, tenant-friendly summary of this industrial space under 50,000 SF. Include:

• What the space is (whitebox? improved?)
• Key specs (clear height, shipping, power, office %)
• Parking
• Neighbouring tenants
• Pros
• Cons
• Ideal tenant types

Tone: neutral, factual.
reviewsscoring

4 · Landlord Review Aggregation

Summarize all reviews for this landlord. Categorize into:

• Responsiveness
• Maintenance quality
• Operating cost transparency
• Renewal negotiation fairness
• Building condition
• Tenant mix compatibility

Provide a 1–10 score for each category.
environmentalrisk

5 · Environmental Scan

Analyze environmental data from Ontario well records and other sources. Identify:

• Potential contamination
• Historical spills
• Groundwater issues
• Former industrial uses
• Any red flags

Provide a risk rating from 1–5.
locationdemographics

6 · Drive-Time & Demographics

Analyze drive-time and demographic data for this address. Include:

• 10/20/30 minute labour pool
• Industrial labour concentration
• Transit access
• Traffic patterns
• Proximity to suppliers/customers

Provide a relocation suitability score.

Email ingestion & parsing

ingestionTRREBemail

E1 · Extract raw listing data from TRREB emails

Parse this TRREB email and extract all listing blocks. Identify each listing as For Lease, Leased, For Sale, or Sold. Return the raw text for each listing separately, including any attached data such as remarks, property details, and agent information.
ingestionattachmentsPDF

E2 · Extract attachments

Identify and extract all attachments from this TRREB email, including PDFs, brochures, floor plans, and images. Save each attachment with a filename that includes the MLS number and the listing status.

AI broker workflow

filtering

7 · Space Filtering

Based on the tenant's criteria (size, clear height, shipping, office %, parking, budget, location), filter all available spaces and return the top matches with reasons.
outreachemail

8 · Agent Outreach

Draft a professional email to the listing agent asking:

• Is the space still available?
• Are there any offers?
• Can you provide floor plans, site plans, and updated photos?
• When can tours be scheduled?

Tone: concise, professional.
tourpackage

9 · Tour Package

Generate a tour package summarizing all selected spaces. Include:

• Map
• Key specs
• Photos
• Pros/cons
• Drive-time
• Environmental flags
• Landlord scores
• Questions to ask during the tour

Format cleanly.
